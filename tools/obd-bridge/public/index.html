Setup — USB or Bluetooth Classic

Works with USB ELM327 and Bluetooth Classic dongles that appear as a serial port (COMx on Windows, /dev/cu.… on Mac). BLE-only sticks (e.g. Ancel BD200) are not supported.

  1. Dongle in the car’s OBD port, ignition ON (engine running helps RPM).
  2. USB: plug into the PC. On Windows check Device Manager → Ports for a new COMx. Leave MS/HS switch on HS-CAN.
  3. Bluetooth Classic: pair in OS Bluetooth settings until a serial/COM port appears (not BLE app-only).
  4. Start the bridge: npm run obd-bridge from the repo root.
  5. Refresh ports → pick the USB or BT serial entry → baud 38400 (try 9600 / 115200 if needed).
  6. Connect → toggle Live poll. Use Debug log if anything fails.
