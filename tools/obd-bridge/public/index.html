Setup

Pick an adapter below. ELM327 is the production path (USB / Bluetooth Classic serial). VAS 6154 is experimental (J2534 PassThru / DoIP raw transcript on Windows) — not a full UDS product stack.

  1. Dongle in the car’s OBD port, ignition ON (engine running helps RPM).
  2. USB: plug into the PC. Device Manager → Ports for a new COMx. Leave MS/HS on HS-CAN.
  3. Bluetooth Classic: pair until a serial/COM port appears (not BLE app-only).
  4. Start the bridge: npm run obd-bridge (or npm start in tools/obd-bridge).
  5. Refresh ports → pick port → baud 38400 → Connect → Live poll.
  1. Install I+ME Actia VAS6154 PassThru drivers (J2534 FunctionLibrary in the registry).
  2. VAS in car OBD port, ignition ON. Prefer USB for lab; note Wi‑Fi / RNDIS IP if using DoIP.
  3. Choose mode PassThru (DLL) or DoIP (host:13400), or Auto.
  4. Check Experimental → Connect → open Debug for raw TX/RX.
  5. See tools/obd-bridge/README.md for DLL / DoIP assumptions.

Connection

DISCONNECTED
Experimental. Opens PassThru and/or DoIP, dumps raw traffic to Debug. No multi-module UDS product features. Does not replace ELM live PIDs.

Live data

Mode 01 PIDs supported by this DME. Priority set (RPM, coolant, speed, voltage, load, MIL) polls every second; secondary PIDs refresh about every 3 seconds while live poll is on.

Connect to see live PIDs.

Fault codes

Generic OBD Mode 03 / 07 / 0A reads the engine emissions ECU (DME) only. Look up meanings in FLAT·SIX Fault Finding. Other modules need manufacturer UDS.

Connect to scan fault codes.

Vehicle info

Mode 09 identity (VIN, calibration ID, CVN, ECU name) — read once on connect, not every poll.

Connect to read vehicle identity.
