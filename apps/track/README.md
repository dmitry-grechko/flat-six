# FLAT·SIX Track UI

Shared Vite + React UI for the offline Track companion (PWA + Electron).

See [`docs/procedures/track-offline.md`](../../docs/procedures/track-offline.md).

```bash
npm install
npm run dev      # http://127.0.0.1:5173 — uses OBD bridge by default
npm run build    # apps/track/dist (also the PWA build)
```
